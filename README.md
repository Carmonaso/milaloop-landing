# Milaloop Landing

Simple "Under Construction" landing page, deployed to GitHub Pages.

## Local preview

Open `index.html` directly in a browser, or serve it:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deploy

Push to `main`. The `Deploy to GitHub Pages` workflow (`.github/workflows/deploy.yml`) builds and publishes automatically.

In the repo settings, under **Pages**, set the source to **GitHub Actions** (one-time setup).
